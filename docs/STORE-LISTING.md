# Microsoft Store 三語文案

在 Partner Center 為產品 `9P2LHK1M4M0G` 建立以下三個語言的商店頁面。套件清單已包含相同語言的應用名稱與簡短說明；商店頁面文字仍須在 Partner Center 分別填寫。上架前請依實際通過認證的功能核對描述。

## 简体中文（zh-CN，默认）

**名称：** MS 游戏栏处理器

**简短说明：** 处理 Game Bar 协议请求，避免反复出现“选择应用”弹窗。

**说明：** 连接手柄或按 Win+G 时，Windows 可能尝试打开 Game Bar 协议并反复要求选择应用。MS 游戏栏处理器接收这些请求，默认安静地忽略，并记录最近事件。安装后可在 PowerToys Command Palette 中搜索 ms-gamebar-handler，查看最近事件和管理工具。需要 Windows x64 及已启用 Command Palette 的 PowerToys。规则编辑和 Steam 大屏幕自动启动暂未开放。

## 繁體中文（zh-TW）

**名稱：** MS 遊戲列處理器

**簡短說明：** 處理 Game Bar 通訊協定要求，避免反覆顯示「選擇應用程式」視窗。

**說明：** 連接控制器或按 Win+G 時，Windows 可能嘗試開啟 Game Bar 通訊協定，並反覆要求選擇應用程式。MS 遊戲列處理器接收這些要求，預設靜默忽略，並記錄最近事件。安裝後可在 PowerToys Command Palette 中搜尋 ms-gamebar-handler，查看最近事件及管理工具。需要 Windows x64 與已啟用 Command Palette 的 PowerToys。規則編輯和 Steam 大螢幕自動啟動尚未開放。

## English (United States, en-US)

**Name:** MS Game Bar Handler

**Short description:** Handles Game Bar protocol requests without repeated app selection prompts.

**Description:** Connecting a controller or pressing Win+G may cause Windows to open a Game Bar protocol and repeatedly ask you to choose an app. MS Game Bar Handler receives these requests, ignores them by default, and records recent events. After installation, search for ms-gamebar-handler in PowerToys Command Palette to view recent events and management tools. Requires Windows x64 and PowerToys with Command Palette enabled. Rule editing and automatic Steam Big Picture launch are not available yet.
